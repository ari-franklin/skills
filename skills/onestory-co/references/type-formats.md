# Type Formats

Use these compact definitions of done.

## User Story

```md
## Definition of Done
- Given <starting context>
  When <action or trigger happens>
  Then <user-visible or business-visible outcome>
```

Add up to three concise scenarios when needed.

## Spike

```md
## Definition of Done
### Outputs
- <artifact to deliver>
- <artifact to deliver>

### Questions to Answer
- <unknown that must be resolved>
- <unknown that must be resolved>
```

## Chore / Support

```md
## Definition of Done
- <task to complete>
- <task to complete>
- <task to complete>
```

## Bug

```md
## Definition of Done
### Observed Behavior
<what is happening now>

### Expected Behavior
<what should happen instead>
```
