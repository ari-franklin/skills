# Axios-Style Labels

## Purpose

Use familiar Axios-style labels to create fast recognition and scannability.

## Preferred Labels

Use these labels when they fit:

- **Why it matters**: impact, stakes, relevance, business value
- **The big picture**: broader context or strategic frame
- **What's new**: the announcement, change, launch, result, or update
- **By the numbers**: metrics, dates, counts, percentages, costs, usage, deadlines
- **Between the lines**: implication, subtext, hidden tension, nuance
- **What we're hearing**: feedback, signals, sentiment, qualitative input
- **What to watch**: next risk, milestone, dependency, signal, or deadline
- **Reality check**: constraint, caveat, limitation, or hard truth
- **Yes, but**: counterpoint or tradeoff
- **Go deeper**: optional background link or context
- **Bottom line**: final takeaway

## Labels To Avoid

Avoid generic corporate labels unless the user explicitly requires them:

- Overview
- Background
- Update
- Status
- Key takeaways
- Learnings
- Next steps
- Action items

If the content needs actions, use an Axios-style label and write action bullets inside it.

Example:

```markdown
**What to watch**
- **Legal review** is the gating item for Friday's announcement.
- **Pilot feedback** will decide whether we expand next week.
```

## Label Rules

- Use 3-6 sections for most briefs.
- Do not use every possible label.
- Put **Why it matters** near the top unless the format has a stronger required lead.
- Use **Bottom line** only when the final sentence sharpens the brief.
- Keep labels stable and recognizable.
