# Rewrite

Purpose: convert existing prose into a shorter Axios-style brief.

## Output

```markdown
# <headline under 60 characters>

**Why it matters:** <one sentence on impact>

**What's new**
- **<2-4 word anchor>** <key rewritten point>
- **<2-4 word anchor>** <key rewritten point>

**What to watch**
- **<2-4 word anchor>** <risk, open item, or next action>

**Bottom line:** <one memorable takeaway>
```

## Rules

- Preserve facts, not source phrasing.
- Omit **What to watch** if there is no real risk, open item, or action.
- Aim to cut 30-50% from the source unless the source is already concise.
