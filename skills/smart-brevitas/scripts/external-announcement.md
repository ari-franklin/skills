# External Announcement

Purpose: create a public-facing announcement or press-style brief.

## Output

```markdown
# <punchy news-driven headline>

**Why it matters:** <why the public, market, customers, or industry should care now>

**What's new**
- **<2-4 word anchor>** <core announcement>
- **<2-4 word anchor>** <supporting concrete detail>

**The big picture:** <short context>

**Quote:** "<refined quote from source>"

**Bottom line:** <ultimate takeaway>
```

## Rules

- Omit **Quote** if the source does not include one and the user did not ask to draft one.
- Do not invent customer, executive, or company claims.
- Keep public claims precise and verifiable.
