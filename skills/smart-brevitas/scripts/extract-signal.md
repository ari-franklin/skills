# Extract Signal

Purpose: identify the real news and best communication shape before drafting.

## Output

```markdown
**Signal:** <the real news>

**Audience:** <primary reader>

**Why it matters:** <stakes>

**Noise to cut**
- <detail to remove>
- <detail to remove>

**Best format:** <weekly-update | external-announcement | executive-brief | internal-announcement | rewrite>

**Bottom line:** <next writing move>
```

## Rules

- Use this when the source is messy or the user asks what matters.
- Do not draft the full brief unless the user asked for both extraction and rewriting.
- If the signal is ambiguous, ask one question or use Superloop.
