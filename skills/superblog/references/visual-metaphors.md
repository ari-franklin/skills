# Visual Metaphors

Use metaphors that clarify a decision or tension. Keep them concrete and brief.

## Good Metaphor Patterns

- Tool metaphors: hammer, swiss army knife, crutch
- Choice metaphors: yes/no/not now, open doors, reservations, last responsible moment
- Work system metaphors: guardrails, boundaries, defaults, bottlenecks
- Craft metaphors: practice, muscle memory, shared defaults
- Option metaphors: holding a reservation, buying tickets before they sell out, parallel paths

## How To Use Them

- Introduce the metaphor only after the reader understands the problem.
- Use it to reveal a tradeoff, not decorate a paragraph.
- Return quickly to product work.
- Do not stack multiple metaphors in one section.

## Avoid

- Grand nature metaphors unless the user asks for a poetic essay
- Sports cliches
- War metaphors
- Metaphors that make the argument feel more dramatic than the underlying issue
