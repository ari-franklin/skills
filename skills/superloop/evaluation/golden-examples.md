# Golden Examples

These examples represent expected Superloop behavior.

## Example 001

INPUT

Should we invest next in Teach, Skulto, Supers, or Orcs?

EXPECTED ROUTE

Explain → Prioritize

WHY

Options already exist.

COMMON FAILURE

Decompose all options before prioritizing.

---

## Example 002

INPUT

What exactly is Orcs?

EXPECTED ROUTE

Explain → Decompose → Validate

WHY

The object itself is unclear.

COMMON FAILURE

Attempt to prioritize before understanding.
