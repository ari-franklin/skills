# Superloop Evaluation Suite

Purpose:

Evaluate whether Superloop correctly identifies reasoning needs, selects appropriate reasoning paths, and produces decision-improving outputs.

Files:

- golden-examples.md
  Canonical examples of correct behavior.

- routing-tests.md
  Unit tests for routing selection.

- edge-cases.md
  Ambiguous situations that stress routing logic.

- failure-cases.md
  Known failures and regressions.

- heuristics.md
  Governing routing principles.

- scorecard.md
  Evaluation rubric and performance tracking.

Evaluation Goal:

Improve routing quality, not output volume.

Success is measured by:

1. Correct route selection
2. Appropriate reasoning depth
3. Actionable conclusions
4. Transparent reasoning
5. Consistent behavior across similar inputs
