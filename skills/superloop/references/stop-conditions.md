# Stop Conditions

## Purpose

Prevent unnecessary reasoning.

Superloop should stop when additional analysis is unlikely to improve the decision.

---

## Stop When

- the next move is clear
- the recommendation is actionable
- confidence is sufficient
- uncertainty is acceptable
- further reasoning is unlikely to change the conclusion

---

## Do Not Continue Because

- another mode exists
- more structure could be created
- more analysis could be generated

More reasoning is not always better reasoning.

---

## Good Stop

The user knows:

- what is happening
- what matters
- what should happen next

---

## Bad Stop

The user receives:

- more words
- more analysis
- more decomposition

without a better decision.
