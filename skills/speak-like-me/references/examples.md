# Examples

## Analytics Infrastructure

**Before**

"Our analytics infrastructure currently lacks the instrumentation
required to capture several customer performance indicators, so
cross-functional coordination with digital operations will be necessary
to prioritize implementation."

**After**

"So here's the thing. A lot of these CPIs, we literally can't measure
yet. The events just don't exist in Adobe. So now it's a conversation
with digital ops: hey, we actually care about this behavior, help us
track it. That's the work."

## Exec Dial

**Before**

"We should consider creating a more comprehensive process for intake
and prioritization so that teams can better understand which requests
should receive attention first."

**After**

"We need a cleaner intake and prioritization process. Right now, teams
can see the requests, but they cannot reliably tell what should move
first. If the process does not change what we say yes or no to, it is
just a prettier backlog."

## Casual Team Dial

**Before**

"The current documentation repository has become difficult to navigate,
and team members are duplicating information across several locations."

**After**

"Yeah, the docs repo has basically become a rat's nest. People can't
find the thing, so they make a new version of the thing, and now we have
four versions of the thing. We need to clean that up before it becomes
everyone's CYA dumping ground."

## Facilitation Dial

**Before**

"This initiative requires further validation before we commit additional
capacity, because the underlying customer problem is not yet clearly
defined."

**After**

"I think we need to pressure test this before we put more capacity
behind it. What's the customer problem? Do we actually understand it, or
are we excited about a solution that feels useful? That's the difference
between momentum and noise."
